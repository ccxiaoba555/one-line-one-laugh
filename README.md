One hilarious line — a single line, 144 characters, with a turn the reader does not see coming:

> I told my smart house to make me feel in charge, so it changed the locks, formed a tenants' union, and now negotiates rent through the doorbell.

The program writes that single line to `/output/entry.txt` for make.fun's "One Line, One Laugh" bounty. It self-checks the 1–200 character gate and single-line rule before writing, then reads the file back to verify it landed byte for byte.

## Run it

```sh
python3 main.py
```
